## 1. HotCRP 提交元数据（icse2027-nier.hotcrp.com）

**Title**（与稿件一致）
> Agentic Metabolic Engineering: Managing Workspace Byproducts in AI-Driven Software Development

**Abstract**（= 稿件摘要，直接复制）
> The rapid adoption of vibe coding and agentic software development has created a new class of technical debt: the uncontrolled accumulation of workspace byproducts—caches, logs, draft files, and abandoned implementations. While recent work has identified workspace state drift as a fundamental bottleneck in agent performance, no existing framework provides a systematic, policy-driven approach to managing the lifecycle of these byproducts. We introduce Agentic Metabolic Engineering, a paradigm that treats the agent workspace as a living system requiring digestion, not just deletion. We define four metabolic phases—catabolism (audit), sequestration (clean), verification (verify), and anabolism (rollback)—and present workspace-metabolism, a zero-dependency Python CLI that implements this paradigm. Through a reproducible benchmark simulating 30 agentic loops, we show that a metabolized workspace maintains 2 active files versus 242 in an unmanaged workspace, while preserving full auditability and rollback capability. Our framework fills the gap between workspace governance during execution (Harness Engineering, Loop Engineering) and workspace cleanup after execution, offering the first verifiable, policy-driven lifecycle management for agent-generated byproducts.

**Keywords**（用逗号分隔）
> agentic software engineering, technical debt, workspace management, vibe coding, file lifecycle, reproducibility

## 3. Overleaf 编译清单（9.6 前完成）

### 步骤
1. overleaf.com → New Project → Upload Project（或 Blank + 粘贴）
2. 上传/粘贴两个文件：`nier-icse2027.tex` + `nier-references.bib`（**不要**上传 PDF；acmart 模板 Overleaf 自带，若报缺类文件：Menu → 顶部搜索 "acmart" 添加模板文件，或上传 acmart.cls + acmart.bib + ACM-Reference-Format.bst，可从 CTAN 下载）
3. 左侧 Menu（菜单）→ Compiler 选 **pdfLaTeX** → 点 Recompile
4. 检查右下角 Log：无红色 Error；黄色 Warning 里 "undefined citation" 必须为 0（出现则说明 .bib 没被读取，检查文件名/拼写）
5. 预览确认：标题、摘要、两个表格、参考文献 [1]–[15] 齐全；总页数 ≤ 4 页正文 + ≤1 页参考文献
6. 下载 PDF → 检查 PDF 属性（文件 → 属性 → 作者应为空/Anonymous）

### 常见报错速查
| 报错 | 原因 | 处理 |
|---|---|---|
| `File acmart.cls not found` | 模板类缺失 | Menu → 添加 acmart 官方模板文件，或换用 Overleaf 的 "ACM Conference Format" 现成模板后粘贴正文 |
| `undefined citations` | bib 未编译 | 确认编译序列含 bibtex：Menu → 编译方式选 "pdfLaTeX + BibTeX"（若选项没有，在项目根放 `latexmkrc` 或手动连续 Recompile 两三次） |
| 中文乱码 | 文件编码 | 本项目为纯英文稿，若粘贴过程混入中文注释，删除即可 |
| `Overfull hbox` | 排版警告 | 可忽略（不影响提交） |
