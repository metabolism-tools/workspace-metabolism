## Measurements

| Measure | Raw observation and denominator |
| --- | --- |
| Due obligations | Count all eligible slots, including missed, late, held and failed ones; separate uninstrumented history |
| Discovery delay | Detection minus missed deadline, or fault onset if independently known; otherwise an interval or unknown |
| Stale healthy display exposure | Time an observed display represented failed/stale evidence as current; last-good/first-bad bounds if exact onset is unknown |
| Downstream correctness | Accepted / rejected / missing checks, with count of eligible outputs |
| Human supervision | Measured checking, correction and rescue minutes; takeover count; who/what was observed |
| Business decisions and creative work | Separate from supervision; unknown if inseparable |
| Notifications | Necessary / unnecessary / missed; send failures, retries, sent and acknowledged counts; unresolved incident count |
| Cost | Actual tokens, compute, storage, retries, verification and recovery; unknown components stay unknown |
